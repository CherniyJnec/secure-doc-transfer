# 📋 RUNBOOK: Secure Doc Transfer (Diploma Project)

Этот документ содержит инструкции по запуску, тестированию и демонстрации децентрализованного приложения для защищенной передачи документов.

---

## 🚀 Быстрый старт (Автоматический запуск)

Для запуска всего стека одним кликом используйте скрипт `start.bat` в корне проекта.

1.  Убедитесь, что **IPFS Desktop** установлен и запущен.
2.  Запустите файл `start.bat`.
3.  Дождитесь открытия трех окон терминала:
    *   **Hardhat Node**: Локальный блокчейн.
    *   **Deploy Contract**: Деплой смарт-контракта (завершится сообщением "ДЕПЛОЙ ЗАВЕРШЁН").
    *   **Frontend (React)**: Веб-интерфейс (будет доступен по адресу `http://localhost:3000`).
4.  Откройте браузер по адресу `http://localhost:3000`.

> ⚠️ **Важно:** Не закрывайте окна терминалов во время работы приложения.

---

## 🔧 Ручной запуск (Пошаговая инструкция)

Если автоматический скрипт не работает или требуется ручной контроль, выполните следующие шаги в отдельных терминалах.

### Шаг 1: Запуск локальной ноды (Терминал 1)
Запустите локальную сеть Hardhat. Она будет майнить блоки мгновенно.
```bash
npx hardhat node
```
*Оставьте этот терминал открытым.*

### Шаг 2: Деплой смарт-контракта (Терминал 2)
В новом окне терминала (из корня проекта) выполните деплой контракта в локальную сеть.
```bash
npx hardhat run scripts/deploy.js --network localhost
```
*Убедитесь, что в выводе появился адрес контракта и сообщение о сохранении конфига.*

### Шаг 3: Запуск фронтенда (Терминал 3)
В третьем окне терминала перейдите в папку фронтенда и запустите dev-сервер.
```bash
cd frontend
npm run dev
```
*Приложение будет доступно по адресу `http://localhost:3000` (или `5173`, если порт занят).*

### Шаг 4: IPFS Desktop
Убедитесь, что приложение **IPFS Desktop** запущено и работает (зеленый значок в трее). Без него загрузка файлов работать не будет.

## 🦊 Настройка MetaMask

Для взаимодействия с приложением необходимо настроить кошелек MetaMask на работу с локальной сетью.

### Параметры сети
| Параметр       | Значение                          |
|----------------|-----------------------------------|
| Network Name   | `Hardhat Local`                   |
| RPC URL        | `http://127.0.0.1:8545`           |
| Chain ID       | `31337`                           |
| Currency Symbol| `ETH`                             |

### Тестовые аккаунты
Импортируйте эти аккаунты в MetaMask, чтобы иметь средства для транзакций.

| Аккаунт | Адрес                                      | Приватный ключ                                                         |
|---------|--------------------------------------------|------------------------------------------------------------------------|
| #0      | `0xf39Fd6e51aad88f6F4ce6aB8827279cffb92266`| `v`   |
| #1      | `0x70997970C51812dc3A010C7d01b50e0d17dc79C8`| `0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d`   |

> ⚠️ **Критически важно:** После перезапуска ноды (`npx hardhat node`) состояние блокчейна сбрасывается. Обязательно выполните **Сброс аккаунта** (Reset Account) в настройках MetaMask для каждого импортированного аккаунта, иначе транзакции будут падать с ошибкой nonce.

## ✅ Тестирование и Проверка

### Unit-тесты смарт-контракта
Запустите тесты из корня проекта, чтобы убедиться в корректности логики контракта.
```bash
npx hardhat test
```
**Ожидаемый результат:** `5 passing`

### Покрытие кода (Code Coverage)
Для оценки качества тестирования запустите:
```bash
npx hardhat coverage
```

### Полный цикл проверки функционала
1.  **Подключение:** Откройте `http://localhost:3000` и подключите **Account #0**.
2.  **Отправка:** Выберите любой файл (PDF, изображение), введите адрес **Account #1** (`0x7099...`) и нажмите «Отправить». Подтвердите транзакцию в MetaMask.
3.  **Смена пользователя:** Переключите аккаунт в MetaMask на **Account #1**.
4.  **Обновление:** Обновите страницу браузера (`F5`).
5.  **Проверка статуса:** В списке документов должен появиться новый файл со статусом «⏳ Ожидает».
6.  **Подтверждение:** Нажмите кнопку «Подтвердить получение» и подпишите транзакцию. Статус изменится на «✅ Получено».
7.  **Скачивание:** Нажмите ссылку «📥 Скачать файл из IPFS». Файл должен открыться в новой вкладке.

## 🛠 Устранение неполадок (Troubleshooting)

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| `EADDRINUSE :8545` | Порт занят другой нодой | Найдите процесс на порту 8545 и завершите его, или используйте уже запущенную ноду. |
| `Failed to fetch` при отправке файла | IPFS не отвечает или CORS ошибка | Перезапустите IPFS Desktop. Убедитесь, что настроены CORS заголовки (см. `start.bat`). |
| `❌ Неверная сеть` в интерфейсе | Несовпадение Chain ID | Проверьте, что в MetaMask выбран Chain ID `31337`. Сбросьте аккаунт в MetaMask. |
| Документ не появляется у получателя | Кэш фронтенда или ошибка доступа | Обновите страницу (`F5`). Проверьте консоль браузера (F12) на наличие ошибок. |
| `HH502` / Ошибка компиляции | Проблемы с доступом к репозиториям solc | Выполните `npx hardhat clean --global` и убедитесь, что используется локальный `solcjs`. |
| Транзакция зависает | Низкий газ или конфликт nonce | Сбросьте аккаунт в MetaMask (Settings → Advanced → Reset Account). |
