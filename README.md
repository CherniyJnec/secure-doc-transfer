# 🔒 Secure Doc Transfer

Децентрализованное приложение (dApp) для защищенной передачи конфиденциальных документов с использованием гибридной архитектуры блокчейна и IPFS.

## 🚀 О проекте

Проект решает проблему доверенной передачи файлов между сторонами без участия централизованных посредников. Система гарантирует неизменность факта отправки и получения документа, используя Ethereum-совместимый блокчейн для аудита и IPFS для децентрализованного хранения контента.

### Ключевые особенности:
*   **Гибридная архитектура:** Хранение метаданных и прав доступа on-chain (Solidity), хранение самих файлов off-chain (IPFS).
*   **Контроль доступа:** Строгая проверка прав отправителя и получателя через смарт-контракт.
*   **Подтверждение получения:** Механизм двухстороннего подтверждения факта доставки документа.
*   **Product-Ready подход:** Покрытие unit-тестами, использование стандартов безопасности OpenZeppelin (`ReentrancyGuard`, `Ownable`).

## ⚡ Быстрый старт

Для запуска всего стека в локальной среде выполните следующие шаги:

1.  Убедитесь, что у вас установлены [Node.js](https://nodejs.org/) и [IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/).
2.  Клонируйте репозиторий и установите зависимости:
    ```bash
    git clone https://github.com/CherniyJnec/secure-doc-transfer
    cd secure-doc-transfer
    npm install
    cd frontend && npm install && cd ..
    ```
3.  Запустите автоматический скрипт сборки (Windows):
    ```bash
    start.bat
    ```
    *Скрипт автоматически запустит ноду Hardhat, задеплоит контракт и поднимет фронтенд.*

4.  Откройте браузер по адресу: `http://localhost:3000`

> **Важно:** Для работы приложения необходимо настроить MetaMask на сеть **Hardhat Local** (Chain ID: 31337, RPC URL: `http://127.0.0.1:8545`).

## 🏗 Архитектура

Приложение построено по принципу разделения ответственности:
1.  **On-Chain (Smart Contract):** Хранит только криптографические хеши (CID) файлов, адреса участников и статусы транзакций. Это обеспечивает низкую стоимость газа и высокую скорость работы.
2.  **Off-Chain (IPFS):** Файлы шифруются и хранятся в распределенной сети IPFS. В блокчейн передается только уникальный идентификатор контента.
