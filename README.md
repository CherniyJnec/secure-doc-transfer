# secure-doc-transfer
Блокчейн приложение для передачи данных. Работает полностью локально: Ganache как блокчейн, Hardhat как среда разработки, локальный фронтенд. A blockchain application for data transfer. It works completely locally: Ganache as a blockchain, Hardhat as a development environment, and a local frontend. Solidity - contract, React+Vite - frontend.
